# Personal Expense Tracker 💰

A beginner-friendly Python project to manage daily expenses using Object-Oriented Programming and JSON file storage.

## Features

- Add new expenses
- View all expenses
- Calculate total expenses
- Delete expenses
- Search expenses by category
- Monthly expense report
- Category-wise expense summary
- Input validation
- Save and load expenses using JSON

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- JSON
- datetime module

## Project Structure

```text
Personal-Expense-Tracker/
│
├── main.py
├── expense.py
├── manager.py
├── expenses.json
└── README.md
```

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python3 main.py
```
